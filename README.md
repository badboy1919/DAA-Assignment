# DAA Assignment — Search & Algorithm Solutions

Solutions for **Design & Analysis of Algorithms** coursework, organized by problem number. Implementations cover classic search techniques — linear scan, binary search, and matrix traversal — in both **Java** and **Python**.

## 📂 Problems

| File | Problem | Approach | Language |
| :--- | :--- | :--- | :--- |
| `1/33.java` | Search for a target in an array | Linear scan — O(n) | Java |
| `1/34.py` | Search insert position of a target | Binary search — O(log n) | Python |
| `1/74.java` | Search a target in a 2D matrix | Nested-loop traversal — O(n·m) | Java |
| `1/162.java` | Find peak element in an array | First-descent scan — O(n) | Java |
| `1/704.py` | Binary search on a sorted array | Classic halving — O(log n) | Python |

## 🧠 Concepts Covered

- **Linear search** — sequential scan with early exit
- **Binary search** — `low`/`high` midpoint halving on sorted input
- **Search space reduction** — peak detection via local comparison
- **2D matrix traversal** — row-major search

## ▶️ Run

Python:

```bash
python 1/704.py
```

Java (single-file run, JDK 11+):

```bash
java 1/162.java
```
